# tahovig.github.io

Source for [tahovig.github.io](https://tahovig.github.io) — a Jekyll site
(GitHub Pages' built-in `minima` theme, no build pipeline to maintain)
hosting project write-ups that go deeper than the
[profile README](https://github.com/tahovig/tahovig) has room for.

## Local preview

```bash
gem install bundler jekyll
bundle init
bundle add jekyll-theme-minima
bundle exec jekyll serve
```

Then open http://localhost:4000.
